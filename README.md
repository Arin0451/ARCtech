# ARCtech — интернет-магазин компьютерной периферии

## 📌 О проекте

ARCtech — это учебный курсовой проект, представляющий собой интернет-магазин по продаже компьютерной периферии.
Основной акцент сделан на современный визуальный стиль, удобство интерфейса и проработанный пользовательский опыт.

Проект реализует базовый функционал интернет-магазина: каталог товаров, навигацию, визуальное представление продукции и пользовательский интерфейс.

---

## 🛒 Ассортимент

В магазине представлены следующие категории товаров:

- компьютерные мыши
- клавиатуры
- наушники
- коврики для мыши
